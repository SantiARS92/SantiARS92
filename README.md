# Hola, soy Santiago Ángel Ruiz Sánchez 👋

**Técnico Superior en Desarrollo de Aplicaciones Multiplataforma | Desarrollador junior**

Soy titulado en DAM por iFP y busco mi primera oportunidad laboral en desarrollo de aplicaciones.

Durante mis prácticas en Supple Software S.L., participé en la creación de un ERP con Java y Angular y trabajé con bases de datos PostgreSQL mediante DBeaver.

Mi trayectoria anterior incluye más de 14 años en hostelería, con experiencia en gestión de equipos y organización del trabajo. Aporto capacidad para resolver problemas, colaborar y adaptarme a nuevos retos.

- **Programación:** Java y programación orientada a objetos.
- **Desarrollo web:** Angular.
- **Bases de datos:** SQL y PostgreSQL.

- **Herramientas:** IntelliJ IDEA, Eclipse, NetBeans y DBeaver.
